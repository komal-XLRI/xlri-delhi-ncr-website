# `features/` — domain slices

Vertical slices that carry XLRI meaning, composed from `components/`. Colocation
by feature rather than by technical type means everything about the faculty
directory lives in one folder — the strongest predictor of whether a developer
can move quickly in year four.

Planned: `navigation/`, `homepage/`, `faculty/`, `programmes/`, `news/`,
`events/`, `admissions/`, `search/`.

Navigation lands in Phase 2, homepage sections in Phase 3.
